# Project: Anime Movie App — Full-Stack Web Application

Act as my senior full-stack developer and coding agent. Help me build a polished, functional Anime Movie App from scratch.

## 1. Required technology stack

These technologies are required for my school activity. Do not replace them with another framework.

**Backend**
- Laravel (PHP)
- MySQL database
- Laravel REST API
- Eloquent ORM and migrations

**Frontend**
- Vue 3
- Quasar Framework
- TypeScript
- Vite
- Axios for API requests

**Development tools**
- Git and GitHub for version control

## 2. Project concept

Build an anime and movie discovery application where users can browse anime titles, inspect details, search for shows, and maintain a personal watchlist.

The design should feel like a modern streaming discovery platform: dark theme, attractive poster cards, cinematic banners, clean typography, responsive layouts, and smooth but restrained interactions.

Do not copy another platform's branding or assets.

## 3. Core features

Implement these features in manageable stages:

1. **Home page**
   - Featured anime section
   - Popular and recently added titles
   - Responsive anime poster grid
   - Navigation to other pages

2. **Anime catalog**
   - Display anime retrieved from the Laravel API
   - Search by title
   - Filter by genre and status where practical
   - Loading, empty, and error states

3. **Anime details**
   - Poster and banner
   - Title, synopsis, genres, release year, status, and rating
   - Button to add or remove a title from the watchlist

4. **Watchlist**
   - Save and remove titles
   - Persist changes in the database, not just temporary frontend state
   - For the initial version, a simple single-user watchlist is acceptable. Do not pretend it has authentication or separate user accounts unless those are actually implemented.

5. **Backend API**
   - Create database migrations and an Anime model
   - Implement endpoints to list, search, view, create, update, and delete anime records as appropriate
   - Implement watchlist endpoints
   - Validate incoming data and return consistent JSON responses

6. **Sample data**
   - Seed the database with a small collection of fictional or appropriately licensed/sample anime records
   - Do not invent external API credentials or rely on a paid service
   - Keep sample data separate from application logic

## 4. Frontend and backend integration

The Vue/Quasar frontend must communicate with Laravel through Axios and the Laravel REST API.

- Configure a development proxy or another appropriate local API configuration.
- Do not hardcode catalog records directly into Vue components as the primary data source.
- Keep API calls in a reusable service layer.
- Read data from Laravel and display it in the interface.
- Handle request failures and empty responses gracefully.
- Keep frontend and backend configuration separate.

## 5. Design expectations

Aim for a polished, dark anime-discovery interface.

- Near-black or deep charcoal background
- High-contrast text and carefully chosen accent colors
- Attractive responsive poster cards
- Clear page hierarchy and consistent spacing
- Desktop, tablet, and mobile support
- Reusable Vue components
- Accessible buttons, labels, and keyboard-friendly interactions
- No unnecessary animations, fake functionality, or excessive dependencies

Prioritize a cohesive and usable application over decorative complexity.
